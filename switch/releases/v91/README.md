native references now point directly to the English label. Eden nightly
`4089cfcffd` showed **Contract**, **Fund Defenses**, and **Leave Palace** in the

the [v90 campaign localization](../v90/README.md). The package was rebuilt
from the Japanese 1.0.2 inputs and all 18 files matched the
[v91 manifest](manifest.json) by SHA-256.
