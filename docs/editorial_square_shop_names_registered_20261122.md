# Square shop names

The Square now uses Spice Shop, Craft Shop, Scent Shop, Gem Shop and Dye Shop. These names match the original categories and the goods each shop sells. The other 13 captions retain their individual source-based wording. The independent commodity headings keep their category terms. [Source, installed references and decisions](../releases/all_routes_editorial_20261122_square_shop_names_candidate/verification/registered_review.json)

Ordinary Syracuse and Lisbon replays verified Spice Shop and Craft Shop. In Syracuse the two-screen changes were confined to the Spice Shop caption cell. Every caption passed the complete native glyph and bounds checks. Startup and 17 regression tests passed, and the clean-input patch reconstructs the ROM byte for byte.
