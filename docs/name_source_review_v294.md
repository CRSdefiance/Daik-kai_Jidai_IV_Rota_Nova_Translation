## Full source epithet

SC3B28R0005 calls her 翔緋鯱. The proposed localized epithet is Soaring Scarlet
Orca, retaining all three components rather than only Orca. This is a localization
inference from the naval-combat context, not an official English name claim.
Kanjipedia defines [翔](https://www.kanjipedia.jp/kanji/0003419200) as soaring/flying,
[緋](https://www.kanjipedia.jp/kanji/0005844400) as vivid deep red, and
[鯱](https://www.kanjipedia.jp/kanji/0003027800) as orca or, in architectural
contexts, shachihoko. The sea-battle/admiral context supports the orca reading.
