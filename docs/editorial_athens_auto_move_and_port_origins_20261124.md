# Athens Auto Move and Fleet Info port origins

An ordinary replay from the preserved Athens save opened Port, Depart and Auto Move, then selected Alexandria. The game displayed an estimate of about 38 sailing days before the destination menu. Charles's “There's no route to that port” appeared after the selection. The estimate, the complete line, Charles's nameplate, the Auto Move caption, and both city names passed glyph checks. The two dialogue records retain their wording. Cancelling through the original menus returned to Athens with the same date and funds. Successful travel is outside this replay's coverage. The two Fleet Info port-object writers have three identified inputs. The active route-arrival branch reads one of the two endpoints of the original route edge. All 354 endpoint cases in the initialized map select ports 0–89, excluding the Missionary slot. A second branch uses the fleet's existing docking byte, and a third forwards the destination after it matches the docking getter. The native tests confirmed the port-pointer conversion and the docking getter's no-target value separately. The upstream values of the stored docking byte remain open. The same offline audit found main-port headquarters in all 21 startup company rows. The identified reassignment loops choose from ports 0–113, and the clear path writes 115. One docking path can inherit the headquarters byte. Other headquarters producers, saved docking values, and the five archived COMMON display paths remain open.
