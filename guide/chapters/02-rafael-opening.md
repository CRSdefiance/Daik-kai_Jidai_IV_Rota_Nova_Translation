# Rafael: from Lisbon to the first Africa assignment

**Nintendo DS research draft — 2026-10-11.** This opening ends with the Lisbon palace assignment. It follows a DS-specific published event sequence; it has not yet been tested as a complete playable route.

## Before sailing

**Keep the original ship, Carteira (カルテイラ), until Cesare joins.** Selling it beforehand reportedly blocks recruitment. Retain its original name while following this draft. [Dekuno, 注意すること and スタート](https://dekunobou-rotanova.seesaa.net/article/48270717.html).

Create a separate save before changing ships. This is an editorial precaution; the save-slot instructions still need a DS controls check.

### Use Julio's translated preparation tutorial

Choose **Ask him.** for guided preparation; **Prepare alone.** declines it. These are our accepted translation labels, from [the Lisbon choices](../../translations/raphael_intro_lisbon_choice_fixed_v1.json), `DK4_MES_B44_R0454` / `R0456`. Choosing the tutorial is this guide's recommendation for a first playthrough, not a reported story requirement.

Our [accepted tutorial translation](../../translations/raphael_natural_v2_b137_b141.json) explains that a ship needs sailors, then instructs you to assign them using the flagship option for a one-ship fleet (`DK4_MES_B138_R0006`, `R0021`). Follow that preparation before the route below. DS button/touch instructions will be added after screen verification.

## Using the route

Treat the table as a sequence to follow, rather than a proven dependency graph. For example, R05 records two encounters in one source entry; the source does not establish that both are mandatory gates for R06. If an event fails to appear, record the current crew, ship ownership, location, previous events, and date before trying an alternative.

The source does not specify sailing duration for R01, encounter coordinates for R05, or all hidden flags for R07–R10. Do not interpret those omissions as instructions to wait a fixed number of days or travel to guessed coordinates.

Names and choice labels follow our existing translation work where located; provenance and remaining naming questions appear in the [glossary](../research/glossary.md). Local translation records establish wording, not hidden gameplay prerequisites. Port regions here follow the source's game organization, which should be checked against the DS map before publication.
