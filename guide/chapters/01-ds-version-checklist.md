## Publication checks

- [ ] Each mechanic has a platform-qualified source and evidence status.
- [ ] Each treasure row has a DS acquisition record; no automatic transfer from PSP.
- [ ] Controls use DS buttons and touch input demonstrated in context.
- [ ] Prices, combat advice, and route suggestions name their tested conditions.
- [ ] Bug claims identify affected release and reproduction steps.
- [ ] Screenshots name the ROM/version and emulator or physical hardware.

The wiki's HD sections describe a separate version. Its [general guide](https://w.atwiki.jp/offlinedaikoukai/pages/19.html), 公式Webマニュアル section, links a Switch/Steam manual. That manual cannot establish DS controls.

## Evidence upgrade procedure

For each V-ID, attach a reproducible DS observation using the [fact record template](../research/research-plan.md). Keep the source report even if the test disagrees. Record the precise save state, actions, and result; distinguish original-game behavior from changes introduced by the English translation.
