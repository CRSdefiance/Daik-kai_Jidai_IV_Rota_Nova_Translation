## Capture evidence

Follow [the existing screenshot rules](../screenshots/README.md) and retain native 256×384 dual-screen originals. Add new filenames rather than replacing another agent's files. Keep ROM version/hash, emulator or hardware, source report, frame number where available, image hash, and prior save/event state in the manifest or associated capture report.

For each request, report `pending`, `captured`, or `verified`, the filename/manifest reference, event ID, language, and any discrepancies with the chapter. Check full text, portrait/name consistency, and legibility before treating a translated-ROM capture as final.

Captions should explain the player action or outcome visible in the image. Use Japanese matching labels where the English name is unsettled. Keep the uncropped original even if a later layout needs a crop.

Captures from one observed branch cannot certify missability or hidden prerequisites. Connect SS05 and SS11 to the branch tests in [the review queue](rafael-opening-review.md). A targeted emulator capture is not a complete playthrough or physical-DS test.
